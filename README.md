# Spotify Clone

A React project exploring a Spotify-inspired music interface and integrations with Spotify-related libraries.

## Tech stack

- React 18 and React Router
- Material UI and Emotion
- Axios
- `react-spotify-api` and `react-spotify-auth`
- Create React App

## Getting started

The application source is inside the nested `spotify-clone/` directory.

```bash
cd spotify-clone
npm install
npm start
```

The development server typically runs at `http://localhost:3000`.

## Available scripts

| Command | Purpose |
| --- | --- |
| `npm start` | Start the React development server |
| `npm run build` | Create a production build |
| `npm test` | Run the test runner |

## Source structure

- `src/components/` — interface components
- `src/hooks/` — custom React hooks
- `src/styles/` — styling
- `src/images/` — images and assets

## Spotify integration

Some features may depend on Spotify authentication or API configuration. Check the implementation for required credentials or environment variables, and do not commit secrets.

This is an independent educational project, not an official Spotify application.
